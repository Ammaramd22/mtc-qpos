QPOS Offline — Tyre Shop
========================

BEFORE FIRST USE
1. Install Laragon (https://laragon.org) OR XAMPP.
2. Copy the QPOS "app" folder into Laragon www\qpos  (document root = public).
3. Create MySQL database: qpos_tyre
4. Copy env.offline.example to app\.env and set DB password.
5. Open start-qpos.bat once and finish QPOS web install / login.

DAILY USE
- Double-click "QPOS Offline" on Desktop (or start-qpos.bat)
- POS opens in the browser — no internet needed

BACKUP
- Run backup-qpos.bat every day (or end of day)
- Keep copies on a USB drive

SUPPORT
- Do not delete the app folder or database
- Call your QPOS installer/support contact for updates
